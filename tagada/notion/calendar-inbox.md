## What each line needs
- **Date** (any format: Nov 3, 11/03, Mon week 1)
- **Platform** (X, LinkedIn, Instagram, Meta ad)
- **Topic or idea** (one line is enough)
- Optional: **Brand** (Tagada, TagadaPay, TagadaRx; if missing, the engine picks the best fit and says why), **Format** (thread, carousel, reel, single post, article, ad), **Pillar**
## What happens to it
1. Each line becomes a row in [Notion page](https://app.notion.com/p/1219f9a57edf498096d606a008546c36), with the original line kept in the Source column.
2. For each row the engine finds 3 to 5 reference posts that already won on that platform for that kind of topic: US brands, creators and operators, scored against their own typical post. Each one is checked live, screenshotted and saved in the [Notion page](https://app.notion.com/p/2f7528f0ad654abe93a39809e992fef0) with its post link, profile link and a no-login view.
3. It writes the design direction (layout, slide or beat count, colors, on-screen text, what to film), the copy ready to paste in the Tagada voice, two alternate hooks, and what needs team confirmation.
4. The pasted block below gets a ✅ line with the date it was processed, so nothing runs twice. Paste a new month underneath at any time.
