### 1. PHP2Shell: the PHP bug that hit Magento and WooCommerce stores
**What it is:** Two critical flaws in PHP itself (CVE-2026-109618 and -109619, CVSS 9.2) allow remote code execution with no login. PHP shipped fixes on Oct 21 (8.5.12, 8.4.27, 8.3.36, 8.2.35); the NSA put out an advisory the same morning, and sites like 4chan and DeviantArt went read-only or offline. Because the bug is in PHP, Magento, Adobe Commerce, Shopware and WooCommerce stores are exposed even with clean store code, and plugin updates don't fix it. A follow-up issue (CVE-2026-115560) was disclosed Oct 23.
**Platforms:** X, TikTok, LinkedIn, Reddit, Instagram, YouTube

Sansec (Oct 21, updated Oct 22): no skimming seen so far, and public exploits don't work on a default PHP install. Hostinger (Oct 23): patched all non-VPS hosting by Oct 22, 07:20 UTC.
